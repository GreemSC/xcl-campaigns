For players · from testers' reports on GitHub

Can I play GTA VI on my PC with XCL?

Not yet. Nobody can play it today. The furthest point confirmed by testers is World on screen (25 people in the last 7 days): the game world itself is seen on screen (streets, buildings, trees, characters), even untextured or for a few seconds; not playable.

XCL is a free recompiler that aims to run the Xbox Series version of the game on a PC (Windows, or Linux through Wine or Proton). You need your own copy of the game; this site hosts no game files and no downloads. Below is what the people testing it report: how far each kind of PC gets, and the machines they use. They are their reports, not tests run by this site.

What testers use to reach “World on screen”

System: Windows · NVIDIA, the only one where testers confirm World on screen.

Graphics cards that got this far most often: RTX 5070 Ti (3), RTX 4090 (2), RTX 3090 (2), RTX 5080 (2), RTX 4060 Ti (2).

Graphics memory (VRAM): 16 GB is typical among these testers (median of 25 who gave it).

System memory (RAM): 32 GB is typical (median of 22 who gave it).

This is what most testers who got that far use, not a tested minimum: nobody has measured the smallest machine that works. A smaller PC may still get as far, or not.

How this is counted
  • Source: comments on XCL's GitHub where someone says how far the game got on their own PC. An AI (Claude Haiku) reads each one as data and fills fixed fields: the furthest stage, the system, the GPU, and the machine (RAM, VRAM, processor, driver). Code keeps a size only if the comment writes it in GB, and a GPU, processor or driver only if it appears word for word; the rest is left empty. The stage is the AI's reading and can be wrong: every line links to its source.
  • "Confirmed": 5 or more different accounts report getting at least that far in the last 7 days (10 from "World on screen" on), as on the status page.
  • Typical = median of the testers who wrote the value, shown from 3 machines. Memory written as the system shows it (31.9 GB, 60 GiB usable) counts as the size installed (32, 64 GB); a size in the GPU's name ("RTX 3060 12 GB") counts as its VRAM. Nobody tested a minimum: low values only show what some testers used.
  • Runs use different XCL versions, patches and settings; the page does not check that they are comparable.
