Does GTA VI run with XCL yet?

Not playable yet. Confirmed: World on screen (25 people).

Can I play it on my PC, and what do I need? →

XCL is a recompiler that aims to run the Xbox Series build of the game on a PC: Windows, and Linux through Wine or Proton. This page sums up what testers and developers report on GitHub, every few minutes, with a link to each source. These are their reports, not tests run by this board. It hosts no game files and no downloads.

For people working on XCL, the board helps coordinate: who works on what in the campaign issues, open pull requests that change the same thing, duplicate issues, every test report by platform, and a JSON API for AI agents. It is made by contributors, not by the XCL maintainers.

How this is counted (and what is not checked)
  • Source: issues and comments on GitHub that name a stage of the game and some hardware. Nobody runs the game for this page; these are what people write.
  • An AI (Claude Haiku) reads each one as data and fills fixed fields: did the author run it themselves, the furthest stage, how the run ended, platform, GPU, commit, time, frame rate, and a sentence describing the screen. Code then drops any GPU, commit, number or sentence that does not appear in the comment. The stage itself is the AI's reading and can be wrong: open the source.
  • "World on screen", "Playable" and "Plays well" need a second model (Claude Sonnet) to agree, and to copy word for word the author's description of what was on screen; without it the report counts as "World loading".
  • A stage is ticked (green) when 5 or more different GitHub accounts report getting at least that far, 10 or more from "World on screen" on. 2 to 4 people: orange, not confirmed. A single report colours nothing. Their runs can use different commits, patches and settings: the board does not check that they are comparable or reproducible.
  • Only reports of the last 7 days count. Spot check on 2026-11-24, a second model re-reading random reports: it agreed on 19 of 20 "World loading", 9 of 10 "First pictures" and 7 of 10 "Title screen" reports, and on 4 of 10 "Menus" reports. Of the 10 disagreements, 8 put the run further and 2 less far: the first reading tends to be cautious.
