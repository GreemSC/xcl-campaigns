Where runs stop

What ended each first-hand run of the game reported on GitHub, counted by wall, with the PRs that work on each wall. The walls, their issues and the notes under them are written by hand, each note dated and with its source; PR states are read from GitHub every pass. Which wall ended a run is read from the report: from its exact stop line when it has one at a known address, else by an AI that must copy the sentence that shows it (no sentence: "cause not said").

1860 first-hand reports read; 1253 say the run stopped; 1 decided by an exact stop line; 241 ran a dev branch (amd-dev, nvidia-dev) or #2057, read from their text. One person counts once per wall.
